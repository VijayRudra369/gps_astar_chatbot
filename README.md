GPS A* Chatbot - Hyderabad is a web-based application built with Python Flask that uses the A* algorithm to find the shortest route between different areas of Hyderabad. Users can enter a start and destination area from available locations such as Hyderabad, Secunderabad, LB Nagar, Banjara Hills, Gachibowli, Hitech City, Medchal, and Miyapur, and the chatbot calculates and displays the optimal route in a chat-like interface. The project uses NetworkX to manage the graph of city connections and Flask to serve the frontend (HTML/CSS/JS). It is easy to run locally by installing the dependencies listed in requirements.txt and launching app.py, making it a simple yet interactive way to explore shortest-path routing in a city.
